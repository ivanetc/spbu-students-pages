# План сдвоенной лекции: Java Collections Framework

Статус: проект для обсуждения с преподавателем до написания полного конспекта и презентации. Дата: 13 ноября 2026. Формат: 2 × 80 минут, Java 21. Подробные источники: [авторский материал](author-analysis.md), [четыре университетских курса](university-research.md), [Java 21](java21-source-notes.md), [сквозной пример](example-contract.md).

## Что студент должен уметь после занятия

1. Выбрать `List`, `Set`, `Map` или `Deque` по требованиям к повторам, доступу, порядку и способу обработки; назвать подходящую стандартную реализацию.
2. Читать упрощённую иерархию `Iterable` → `Collection` → основные семейства и отдельную ветвь `Map`; различать интерфейс, реализацию и служебный класс `Collections`.
3. Пользоваться основными операциями, `for-each`/`Iterator`, `Map.entrySet()` и простейшей сортировкой; понимать изменяемость, представления и порядок обхода.
4. Изобразить массив и размер `ArrayList`, узлы `LinkedList`, корзины и коллизии `HashMap`, связь `HashSet` с `HashMap`; предсказать состояние после добавления, удаления и расширения.
5. Выводить оценку операции из числа шагов; различать худшую, ожидаемую и амортизированную стоимость, не превращая условное O(1) хеш-таблицы в гарантию.
6. Объяснить, почему индексный цикл по `LinkedList` может стать O(n²), а линейный обход через итератор — O(n); применять это как мост к следующей теме про функциональные интерфейсы и Stream API.

## Набор схем для будущего конспекта и презентации

1. Карта интерфейсов Java 21 с отдельной ветвью `Map` и пометкой об упрощении `Sequenced*`.
2. Четыре требования к университетским данным и выбранные контракты.
3. `ArrayList`: занятые ячейки, свободная capacity, сдвиг и расширение.
4. `LinkedList`: два конца, `prev`/`next`, число переходов к позиции.
5. `HashMap`: корзины, два ключа в одной корзине, `equals` и перехеширование; различать учебную схему и OpenJDK.
6. `HashSet` поверх `HashMap` и `ArrayDeque` как кольцевой массив — компактные схемы.

Эти вопросы не требуют отдельных устных доказательств за 160 минут.

**За рамками этой темы:** параллельные коллекции, полная реализация красно-чёрного дерева, пользовательская реализация итератора, тонкости `Spliterator`, Streams и лямбда-синтаксис. Следующая лекция покажет функциональные интерфейсы, лямбды и Stream API поверх уже понятных источников данных и обхода.

## Риски для конспекта

- Исходная лекция 6 ссылается на Java 26; новые ссылки и примеры должны быть Java 21. `Sequenced*` уже существуют в 21, но полный их API не укладывается в план.
- Не выдавать конкретную формулу роста `ArrayList`, пороги tree bins или индекс корзины OpenJDK за спецификацию `List`/`Map`. Дать в заметке «как устроено в OpenJDK 21».
- Не утверждать, что `LinkedList` всегда быстрее при вставке, а `HashMap` гарантирует O(1) в худшем случае.
- Сортировку дать на уровне использования и выбора порядка без синтаксиса лямбд, поскольку это следующая тема курса.
